# 🚗 LinguaDrive — לומדים שפות בדרך

מורה פרטי לאנגלית ולספרדית, בנוי לנסיעה. עלות אפס: בלי שרתים, בלי מפתחות, בלי מנויים — הכול רץ בדפדפן.

## מה יש בפנים

- 34 שיעורים מלאים (17 אנגלית + 17 ספרדית): דקדוק בעברית, אוצר מילים עם תעתיק, משפטים, חידון ודיאלוג
- מצב נהיגה: סשן קולי מלא — האפליקציה מדברת, אתה עונה, היא נותנת ציון וממשיכה. פקודות קוליות: skip / repeat / slower / stop
- ציון הגייה: השוואת מה שאמרת מול היעד, מילה-מילה, עם צביעת שגיאות
- חזרות חכמות: שיטת לייטנר — מילה נכונה מטפסת קופסה, טעות מחזירה אותה
- קליניקת הגייה לדוברי עברית: th, ship/sheep, w/v באנגלית; rr, ñ, b=v בספרדית
- עובד אופליין אחרי טעינה ראשונה, נשמר במכשיר בלבד

## שכבת המשחק 🎮

- מפת מסע: כביש מתפתל דרך 6 יחידות, כל שיעור הוא תחנה. תחנות נפתחות בהדרגה, הרכב שלך חונה בתחנה הנוכחית (מצב חופשי זמין בקוד דרך freeRoam)
- נקודות ורמות: עשר דרגות נהיגה — מהולך רגל ועד טורבו אגדי, עם חגיגת קונפטי בכל עלייה
- המוסך: 12 רכבים שנפתחים לפי רמות והישגים; הרכב הנבחר נוסע איתך על המפה
- האתגר היומי: 10 מילים, ניסיון אחד ביום, זהה לכל השחקנים באותו יום — עם שיתוף תוצאה בסגנון וורדל 🟩🟥
- משימות יומיות: שלוש משימות מתחלפות כל יום, בונוס על השלמת שלושתן
- הישגים: 16 תגים — רצפים, מרתונים, דו-לשוניות, בוסים ועוד
- מבחני בוס: בסוף כל יחידה מבחן מסכם של 10 שאלות; עוברים ב-8 ומעלה
- טורבו 60: ספרינט קולי לרכב עם קומבו שמכפיל נקודות, צליל שעולה עם הרצף, ושיתוף שיאים

## איך פותחים עכשיו (בלי התקנה)

פתח את הקובץ העצמאי בדפדפן — הכול כלול בקובץ אחד:

```
linguadrive.html
```

הערה: תרגולי דיבור (מיקרופון) דורשים HTTPS או localhost. בפתיחה כקובץ מקומי — ההאזנה, השיעורים והחידונים עובדים; המיקרופון לא. לחוויה מלאה:

```
cd linguadrive
python3 -m http.server 8000
# → http://localhost:8000
```

## התקנה כאפליקציה (מומלץ) — GitHub Pages

1. צור ריפו חדש והעלה את תוכן התיקייה
2. הפעל Pages:

```
Settings → Pages → Source: Deploy from a branch → main / root
```

3. פתח בטלפון את הכתובת שקיבלת, ואז:

```
Android/Chrome: ⋮ → Add to Home screen
iPhone/Safari:  שיתוף → הוסף למסך הבית
```

## תמיכת דפדפנים

| זיהוי דיבור (ציון הגייה) | ✔ | ✔ | ✔ מתוך Safari |

## פתרון תקלות

- אין קול: ודא שהמכשיר לא במצב שקט; גע במסך פעם אחת (דפדפנים דורשים מגע לפני שמע)
- המיקרופון לא עובד: ודא HTTPS/localhost + הרשאת מיקרופון; באייפון — פתח בספארי ולא מהאייקון
- קול רובוטי: הגדרות ← קול ← בחר קול Google/Natural אם קיים

## הפצה 📦

### דרך 1 — קישור (המומלצת)
פריסה ל-
```
GitHub Pages
```
לפי ההוראות למעלה. משתפים קישור אחד; כל מי שנכנס יכול להוסיף למסך הבית ולקבל אפליקציה מלאה עם אופליין. קובץ ה-
```
.github/workflows/deploy.yml
```
כבר מריץ את כל הבדיקות ופורס אוטומטית בכל דחיפה.

### דרך 2 — קובץ בודד
הקובץ העצמאי
```
linguadrive.html
```
הוא כל המשחק בקובץ אחד — אפשר לשלוח בוואטסאפ/מייל או להעלות לכל אחסון סטטי (כולל
```
itch.io
```
כמשחק דפדפן).

### דרך 3 — חנות אנדרואיד (אופציונלי)
אחרי שיש כתובת חיה, אפשר לארוז ל-
```
Play Store
```
בחינם עם
```
pwabuilder.com
```
(נדרש חשבון מפתח חד-פעמי של גוגל).

### עדכון גרסה
מעלים גרסה בשני מקומות ודוחפים:
```
sw.js        → VERSION
app.js       → APP_VERSION
```
משתמשים פעילים יקבלו הודעת "גרסה חדשה מוכנה" בתוך המשחק ורענון בהקשה.
