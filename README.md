# 🚗 LinguaDrive — לומדים שפות בדרך

מורה פרטי לאנגלית ולספרדית, בנוי לנסיעה — ועכשיו מולטי-פלייר: חשבון חינם מסנכרן את ההתקדמות בין מכשירים ומכניס אותך לטבלאות השיאים.

**🎮 לשחק עכשיו: https://galsened.github.io/linguadrive/**

## מה יש בפנים

- 34 שיעורים מלאים (17 אנגלית + 17 ספרדית): דקדוק בעברית, אוצר מילים עם תעתיק, משפטים, חידון ודיאלוג
- 📖 ספריית מילים: עוד 600 מילים ב-15 חבילות נושא לכל שפה (אוכל, עבודה, נסיעות, רגשות…) עם חיפוש, תרגול חופשי והוספה לחזרות
- מצב נהיגה: סשן קולי מלא — האפליקציה מדברת, אתה עונה, היא נותנת ציון וממשיכה. פקודות קוליות: skip / repeat / slower / stop
- ציון הגייה: השוואת מה שאמרת מול היעד, מילה-מילה, עם צביעת שגיאות
- חזרות חכמות: שיטת לייטנר — מילה נכונה מטפסת קופסה, טעות מחזירה אותה
- מגוון אמיתי: מנוע אנטי-חזרתיות (shuffle-bag) — מילים לא חוזרות על עצמן עד שהמאגר מוצה, בטורבו, בנהיגה ובתרגול החופשי
- קליניקת הגייה לדוברי עברית: th, ship/sheep, w/v באנגלית; rr, ñ, b=v בספרדית
- עובד אופליין אחרי טעינה ראשונה

## שכבת המשחק 🎮

- מפת מסע: כביש מתפתל דרך 6 יחידות; תחנות נפתחות בהדרגה, הרכב שלך נוסע איתך
- נקודות ורמות: עשר דרגות נהיגה, מוסך עם 12 רכבים, 16 הישגים, משימות יומיות
- האתגר היומי: 10 מילים, ניסיון אחד ביום, זהה לכל השחקנים — עם שיתוף בסגנון וורדל 🟩🟥
- טורבו 60: ספרינט קולי עם קומבו; בורר מאגר — "מהשיעורים שלי" או "כל אוצר המילים"
- 🏆 טבלאות שיאים: האתגר היומי וטורבו 60 — מול כל השחקנים הרשומים

## חשבון וסנכרון (אופציונלי)

המשחק עובד מלא גם בלי חשבון — הכול נשמר במכשיר. עם חשבון (אימייל+סיסמה, בחינם):

- ההתקדמות מסונכרנת לענן ונטענת מכל מכשיר
- מיזוג חכם: שני מכשירים שמתקדמים במקביל לא דורסים זה את זה — XP, הישגים וחזרות תמיד מתמזגים קדימה (מונוטוני), הגדרות לפי המאוחר
- אופליין-פירסט: אין רשת? ממשיכים לשחק; הסנכרון מתעדכן כשחוזר החיבור
- מופיעים בטבלאות השיאים
- מחיקת חשבון עצמית מלאה (כולל כל הנתונים בענן)

## ארכיטקטורה (למפתחים)

אפס תלויות, אפס build: קבצי JS נטענים ישירות ב-`index.html`. כל מודול עצמאי:

```
index.html        מעטפת + עיצוב
logic.js          ניקוד הגייה, SRS, XP, אנטי-חזרתיות (טהור — נבדק ב-Node)
merge.js          מיזוג התקדמות בין מכשירים (טהור, מונוטוני, נבדק)
content.js        קורס אנגלית · content-es.js קורס ספרדית
content-bank.js   בנק 300 מילים EN · content-bank-es.js בנק 300 מילים ES
cloud-config.js   תצורת הענן — הקובץ היחיד שמשתנה בין פריסות (null = מקומי בלבד)
backend.js        ספק ענן מוחלף: Supabase REST (אימות + נתונים), בלי SDK
sync.js           מנוע סנכרון אופליין-פירסט (debounce, pull-merge בנקודות בטוחות)
app.js            מסכים, TTS/STT, מצב נהיגה, שכבת המשחק
vocab.js          מסך המילים: ספרייה, חיפוש, תרגול חופשי
account.js        ממשק חשבון + טבלאות שיאים + תור תוצאות אופליין
sw.js             service worker — אופליין
tests/            7 חבילות: logic · content · bank · merge · cloud · static · smoke
```

**החלפת ספק ענן:** לממש מחדש את `backend.js` (אותו API ציבורי) ולעדכן `cloud-config.js`. שאר האפליקציה לא יודעת מי הספק.

**הוספת שפה:** קובץ `content-XX.js` + `content-bank-XX.js` באותה סכמה, ורישום ב-`LANGS` שב-`app.js`.

### Backend (Supabase, free tier)

- פרויקט: `hwkgjsijsjzvtjgjkhpm` (eu-central-1) בארגון GalSened's Org
- אימות: אימייל+סיסמה (GoTrue), בלי אימות-אימייל (הרשמה מיידית)
- טבלאות: `user_state` (שורת מצב לכל משתמש) · `scores` (טבלאות שיאים) — שתיהן מאחורי Row Level Security: משתמש כותב רק את השורה שלו; קריאת טבלאות רק למחוברים; CHECKים בצד השרת (ציון 0–5000, יומי ≤ 10, פורמט לוח, אורך שם)
- מחיקת חשבון: RPC `delete_own_account` (security definer) + cascade
- `keepalive.yml` מפנג את ה-REST פעמיים בשבוע כדי שהפרויקט החינמי לא יוקפא מחוסר פעילות

## פריסה

דחיפה ל-`main` מריצה את `deploy.yml`: כל 7 חבילות הבדיקה ואז פריסה ל-GitHub Pages. עדכון גרסה: לעלות את `APP_VERSION` (app.js) ואת `VERSION` (sw.js) יחד — משתמשים פעילים מקבלים הודעת עדכון בתוך המשחק.

## פתרון תקלות

- אין קול: ודא שהמכשיר לא במצב שקט; גע במסך פעם אחת (דפדפנים דורשים מגע לפני שמע)
- המיקרופון לא עובד: ודא הרשאת מיקרופון; באייפון — פתח בספארי ולא מהאייקון
- קול רובוטי: הגדרות ← קול ← בחר קול Google/Natural אם קיים
- "אין חיבור" בסנכרון: ההתקדמות בטוחה במכשיר; היא תעלה אוטומטית כשיש רשת
